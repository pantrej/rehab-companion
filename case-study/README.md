# Case study

Working files for the Rehab Companion product design case study.

## Boards

The `.excalidraw` files in [`boards/`](boards/) are the visual source of truth for the case study.

- **Edit them in Excalidraw.** Open [excalidraw.com](https://excalidraw.com) (or the Excalidraw
  extension in VS Code), then open the file from this folder. Save back to the same file.
- **Commit and push after changes**, so the repository always holds the latest version.
- **Don't replace them with PNG exports.** An exported image is fine for slides or a portfolio page,
  but it isn't the source file and can't be edited. Keep the `.excalidraw` file as the original.
